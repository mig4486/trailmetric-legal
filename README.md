## Maintenance

Edit content.json or style.css. Run python generate.py, then python verify.py. Commit both sources and generated HTML. No third-party Python dependencies or application builds are required.

GitHub Pages: main branch, root folder; .nojekyll uses the generated static files directly. There are no repository workflows or mobile build tasks.

The iOS licence is Apple's Standard EULA; terms.html is explanatory information, not a replacement custom EULA. Review and update the policy before changing app data collection, advertising, purchases or health integrations.
